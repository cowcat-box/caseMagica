# PRD 评审记录

> 迭代：2026-08 · 状态：待确认

## 一、自评发现的问题与决策点

### P1 需求一：导出范围与内容细节
1. **细纲历史**：书籍设定 zip 中 `setting/chapter-groups/*.md` 是否包含全部历史细纲？（现状：ChapterOutline 展示"最新 + 历史"细纲，历史文件也在此目录）→ 建议：全部包含（保持原目录结构，用户自行取舍）。
2. **章节正文 zip 的目录结构**：`chapters/` 下是否保留分卷目录（`v00001-卷名/`）？→ 建议保留，导入后路径可还原。
3. **book.json 是否进 zip**：含书名/作者/简介元数据，便于材料导入时识别。→ 建议包含。

### P2 需求二：材料导入识别可靠性
4. **识别规则**：按文件名/标题识别太脆（用户文件可能叫 `大纲2.md`）。→ 评审结论：识别失败时弹窗让用户**手动选择目标类型**（枚举：大纲/规则/进度/角色状态/灵感/细纲），保证 100% 可落位。
5. **细纲导入命名**：导入细纲时自动编号（如 `chapter-groups/group<N+1>.md`）不覆盖既有组，需在弹窗中展示最终路径并让用户确认。

### P3 需求三：书籍设定单文件导入导出
6. **粗细纲导出粒度**：单个细纲文件 vs 全部细纲 zip？→ 建议：单文件操作菜单导出当前文件；另提供"导出全部细纲"(zip)。
7. **覆盖确认**：单文件导入覆盖是高频操作，确认弹窗必须展示"目标路径 + 备份位置"，避免误覆盖。

### P4 需求四：Skills 草稿流水线
8. **草稿区位置**：`.casemagica/skill-drafts/<name>/`（user 级数据目录）→ 建议确认；多工作区隔离还是全局共享？→ 建议全局（skill 是用户级资产），草稿带创建时间与来源工作区。
9. **草稿与创建的关系**：确认导入 = 调 `POST /api/skills` 建正式 skill + 删除草稿；冲突（同名 skill 已存在）时提示覆盖/改名。
10. **frontmatter 校验**：草稿导入前必须通过既有 frontmatter 校验（name/description 必填、name 合法字符），避免产生坏 skill。

### P5 需求五：续写推演（重点）
11. **生成方式**：并行 N 个 LLM 调用（成本高、并发受限） vs 单次调用输出结构化 JSON（一次失败全失败、超长 JSON 易截断）？→ 建议：**逐个候选独立调用**（服务端顺序或小并发 2 路），SSE 每完成一个就推送一个，部分失败不影响其他。成本可控、体验渐进。
12. **推演结果持久化**：推演耗时可能较长，用户可能刷新页面 → 建议推演期间结果存内存（复用任务注册），刷新后通过 `GET /api/chat/stream` 类似机制重连恢复；不落盘。
13. **提交为"新建章节"的命名**：复用现有章节文件命名模板 `ch0000N-标题.md`（novel_import.go 同款）；标题来自用户编辑后的候选标题。
14. **提交为"追加章末"的边界**：仅当锚点章节已存在且未确认（或用户主动选择）时允许追加；追加不改变章节确认状态，但会在变更审阅中可见。
15. **编辑器未保存内容**：提交写入走 workspacechange 原子写 + revision 校验；若用户编辑器有未保存修改，提示先保存（或合并）。→ 建议：提交前前端检查编辑器脏状态，脏则提示保存后重试。
16. **推演与 Automation 的关系**：本轮不做 automation 模板集成，仅独立入口。
17. **风格模板来源**：复用 styleref（`.casemagica/styles/*.md`）列表 + 用户自定义文风文本，确认后端推演 API 入参结构。

## 二、评审结论（已确认）

| # | 决策点 | 结论 |
|---|---|---|
| P1-1 | 细纲导出范围 | **用户勾选**（checkbox）：最新细纲 / 全部细纲，保留原目录结构（PRD 1.2 已更新） |
| P1-2 | 分卷目录 | 导出章节正文保留 `v0xxx-卷名/` 分卷目录结构，按原目录结构打包 |
| P2 | 材料导入识别失败 | **手动选择兜底**：弹窗枚举目标类型（大纲/规则/进度/角色状态/灵感/细纲） |
| P4-8 | Skill 草稿区位置 | **用户级草稿区**（多工作区共享，带创建时间与来源工作区） |
| P5-11 | 候选生成方式 | **逐候选独立调用**（小并发 2 路，SSE 逐个推送，部分失败不影响其他） |
| P5-12 | 推演结果持久化 | **落盘持久化**：`.casemagica/continuations/<task-id>/`，刷新可恢复，删除前备份（PRD 5.6 已更新） |
