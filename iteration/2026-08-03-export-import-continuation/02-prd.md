# 产品需求文档（PRD）

> 迭代：2026-08 · 状态：待评审 · 关联：《01-requirements.md》
> 评审确认结论：导出范围由用户自选；导出仅浏览器默认下载；导入=格式导入+材料导入两种；续写推演=方向级/片段级可选 + 短/中/长三级 + 风格模板与方向偏好配置。

---

## 1. 需求一：作品目录导出

### 1.1 目标

在写作模式侧边栏"作品目录"视图新增导出入口，支持用户自选导出范围与格式，导出文件通过浏览器下载。

### 1.2 交互设计

- **入口**："作品目录"视图（`ChapterOutline`）顶部新增"导出"按钮（与"导入"并列）。
- **弹窗**（导出配置）：
  1. **内容勾选**（checkbox 多选，可全选）：导出内容由用户自行勾选——
     - 章节正文（含分卷目录，按原目录结构）；
     - 细纲：**最新细纲** / **全部细纲（含历史）**（二选一，受"细纲"总开关控制）；
     - 大纲、规则、进度、角色状态、灵感、元数据（book.json）。
  2. **格式选择**：随内容联动（勾选章节正文时可选 txt 或 md；含任何内容时可选 zip 打包，见 1.3）。
  3. **确认** → 后端按勾选内容组装（zip 保持原相对目录结构）→ 浏览器默认下载（无目录选择器）。
- 空状态：无可用导出内容时给出双语提示（如"没有可导出的章节"）。

### 1.3 导出内容定义

| 勾选内容 | 格式 | 说明 |
|---|---|---|
| 章节正文 | txt | 复用 `ExportText`（书名/作者/分卷/章节标题+正文），仅"章节正文"被勾选时可用 |
| 章节正文 | md / zip | 每章一个 md，目录结构 `chapters/`（保留 `v0xxx-卷名/` 分卷目录） |
| 细纲（最新/全部） | zip | `setting/chapter-groups/` 原目录结构 |
| 大纲/规则/进度/角色状态/灵感 | zip | `setting/outline.md`、`CREATOR.md`、`setting/progress.md`、`setting/character-states.md`、`ideas.md` 原路径 |
| 元数据 | zip | `book.json` |
| 任意多选组合 | zip | 保持原相对目录结构合并打包 |

- 仅勾选单文件类内容（如仅大纲）时，也支持直接下载单个 md（不强制 zip）。

### 1.4 非目标

- 不做"选择导出到指定目录"（浏览器仅默认下载）。
- 不做游戏模式数据（故事/导演模块）导出——本轮只覆盖写作侧书籍内容。

## 2. 需求二：作品目录导入

### 2.1 目标

在"作品目录"视图新增导入入口，支持两种导入模式：**按格式导入**（小说文本自动分章）与**按材料导入**（书籍设定文件还原）。

### 2.2 按格式导入（复用现有能力）

- 复用现有小说导入流程：选择 `.txt` / `.md` 文件 → 预览（流式分章分析）→ 确认 → 创建新书。
- 仅将入口从作品管理首页迁移/增加到"作品目录"视图（原 HomeView 入口保留）。

### 2.3 按材料导入（新增）

- 选择单个 `.md` 文件 → 自动识别类型：

| 识别规则（文件名/头标题） | 目标落盘路径 |
|---|---|
| `outline.md` 或含"大纲"标题 | `setting/outline.md` |
| `CREATOR.md` 或含"规则/创作规范" | `CREATOR.md` |
| `progress.md` | `setting/progress.md` |
| `character-states.md` | `setting/character-states.md` |
| `ideas.md` | `ideas.md` |
| `chapter-group*.md` 或细纲内容（含分卷/章节组结构） | `setting/chapter-groups/`（自动编号不覆盖） |
| 无法识别 | 弹窗让用户选择目标类型或取消 |

- **安全**：写入前自动备份目标文件到 `.casemagica/backups/settings-import/<timestamp>/`，可回滚。
- 交互：确认弹窗展示"识别类型 → 目标路径 → 原文备份"摘要，确认后写入；写入走服务端原子写。

### 2.4 非目标

- 不导入资料库（lore）结构化条目（用户选择不包含该能力）。
- 不做批量目录导入。

## 3. 需求三：书籍设定导入导出（大纲 / 规则 / 粗细纲）

### 3.1 目标

在书籍设定收藏区（`BookSettingsShortcuts`）为**大纲、规则、粗细纲**三个类型提供独立导入/导出。

### 3.2 交互设计

- 每个设定项的操作菜单（或悬停操作区）新增"导出"与"导入"。
- **导出**：下载该文件的 md 原文，默认文件名与原文件一致（如 `outline.md`）；粗细纲按当前细纲项导出单个文件，另提供"全部细纲"导出 zip。
- **导入**：选择 `.md` 文件 → 预览内容 → 确认覆盖（自动备份原文件，同 2.3）→ 写入。

### 3.3 范围

- 大纲 = `setting/outline.md`；规则 = `CREATOR.md`；粗细纲 = `setting/chapter-groups/*.md`。
- 进度 / 角色状态 / 灵感 不在此需求范围（不提供独立按钮），但随"书籍设定 zip 导出/导入"覆盖。

## 4. 需求四：Skills AI 对话页

### 4.1 目标

在 Skills 一级菜单下新增独立"AI 对话"页，辅助用户炼成 Skill，支持**自动化生成 → 预览 → 导入**流水线。

### 4.2 交互设计

- **入口**：SkillsView 顶部页签新增"AI 对话"（与 编辑器/新建/导入/配置 并列），点开为独立对话面板（复用 AgentChatPane 家族组件）。
- **对话语境**：agent（config_manager 类，origin=`skills_chat`）可加载 `skills-creator` skill；对话中可列出/读取现有 skills（复用 config_manager 工具）。
- **流水线**：
  1. 用户在对话中描述需求，agent 逐步产出 SKILL.md（frontmatter + body）与附加文件；
  2. agent 调用专用工具 `create_skill_draft` 把结果写入服务端草稿区（`.casemagica/skill-drafts/<name>/`），并返回草稿 id；
  3. SSE 事件 `skill_draft` 通知前端 → 对话页出现"Skill 草稿就绪"卡片（草稿名称/描述/文件清单）；
  4. 用户操作：**查看/编辑**（跳入 Skill 编辑器模式加载草稿）→ **确认导入**（创建到 user scope 或 workspace scope，走现有 `POST /api/skills`，成功后列表刷新、草稿删除）→ **丢弃**。
- 支持在对话中要求"重新生成/修改某字段"，agent 可多次产出草稿（覆盖同名草稿前询问）。

### 4.3 非目标

- 不做 Skill 自动触发/调度编排，仅生成与导入。
- 不改变 builtin scope 只读语义。

## 5. 需求五：续写可能性推演（重点）

### 5.1 目标

基于当前书籍章节，推演出**多个续写可能性**，用户可选择、编辑并提交落盘。推演前支持配置**深度（短/中/长）**、**粒度（方向级/片段级）**、**风格模板**与**方向偏好**。

### 5.2 推演深度与粒度定义

| 深度 | 候选数量 | 可用粒度 | 单个候选产出 | 定位 |
|---|---|---|---|---|
| 短推演 | 2~3 | 仅方向级 | 标题建议 + 方向摘要（3~5 句） | 快速头脑风暴，探索多个剧情走向 |
| 中推演 | 3 | 方向级 / 片段级 | 方向级：标题+摘要+走向说明；片段级：+ 300~600 字正文开头 | 标准推演，兼顾方向与可直接使用的开头 |
| 长推演 | 2~3 | 仅片段级 | 标题 + 方向摘要 + 800~1500 字正文片段 + 后续 3~5 章走向规划 | 深度推演，接近可直接成章的素材 |

候选数量与片段长度受配置项约束（见 5.6），数值为默认值。

### 5.3 推演前配置（弹窗表单）

| 配置项 | 说明 | 默认 |
|---|---|---|
| 锚点章节 | 推演基于哪个章节（下拉选当前书籍章节；默认当前打开章节，无打开则最近章节） | 当前章节 |
| 深度 | 短 / 中 / 长 | 中 |
| 粒度 | 方向级 / 片段级（随深度联动，见 5.2 表） | 片段级 |
| 风格模板 | 单选：项目已有文风参考（`.casemagica/styles/*.md` 列表）+ "不使用" | 不使用 |
| 自定义文风 | 自由文本（一段话描述文风，与风格模板二选一或叠加） | 空 |
| 方向偏好 | 自由文本（如"向悬疑推进""引入新配角""强化主线冲突"），可空 | 空 |

### 5.4 推演流程

1. **触发入口**（三处）：编辑器顶部工具栏"续写推演"按钮（当前章节为锚点）；章节树章节项操作菜单；命令面板（`推演续写`）。
2. 弹出推演配置表单 → 点"开始推演"。
3. 后端异步推演（SSE 流式返回候选，逐个产出；可中途中止）。
4. 前端候选面板：候选卡片列表（标题 / 方向摘要 / 片段预览全文展开 / 生成状态）。
5. 用户操作：
   - **选择**：点选一个候选（单选）；
   - **修改**：在卡片内直接编辑标题、方向摘要、正文片段（富编辑）；
   - **提交**：确认目标位置（新建下一章 `ch0000N-标题.md`，或追加当前章节末尾）→ 提交；方向级候选提交为新章节时，弹窗提供"以方向摘要为正文初稿 / 创建空章节（仅标题）"二选一；
   - 也可**重新推演**（保留配置修改后重试）或**全部丢弃**。
6. 提交落盘走工作区变更链路（原子写、可审阅、可撤销，与 agent 写文件一致）。

### 5.5 上下文构建（有界）

推演请求的服务端上下文（均复用现有 `book.State` 能力）：

| 片段 | 来源 | 上限 |
|---|---|---|
| 长期大纲 | `setting/outline.md` | 全文（≤64KB） |
| 创作规则 | `CREATOR.md` | 全文（≤64KB） |
| 进度与角色状态 | `progress.md`、`character-states.md` | 各 ≤32KB |
| 细纲 | `setting/chapter-groups/*.md` | 当前章节所在组优先，≤32KB |
| 前文正文 | 锚点章节 + 前 1~2 章（`read_file` 有界读取） | 每章 ≤ config.continuation.prefix_chars（默认 3000 字） |
| 风格模板 | 用户选择的 styleref 文件内容 | ≤160KB/个（styleref 既有上限） |
| 方向偏好 | 用户输入 | ≤2000 字 |

### 5.6 推演结果持久化（落盘）

- 推演任务与结果落盘到 **工作区** `.casemagica/continuations/<task-id>/`（兼容旧目录名 `.denova`）：
  - `request.json`：推演请求（锚点章节、深度、粒度、风格、偏好）与状态；
  - `candidates/<index>.json`：每个候选（标题/方向摘要/正文片段/状态）。
- 刷新/重连：前端打开"续写推演"面板时按当前锚点章节列出历史推演任务（含状态），可恢复查看已完成候选；进行中的任务可重新连接 SSE。
- 清理：提供"删除推演记录"操作；用户确认后删除对应任务目录（可回滚 → 删除前移动至 `.casemagica/backups/`）。

### 5.7 新增配置项（config.toml）

| 配置 | 默认 | 说明 |
|---|---|---|
| `continuation.max_candidates` | 3 | 单次推演最大候选数（1~5，按深度取 min） |
| `continuation.excerpt_max_chars` | 1500 | 长推演单个片段上限 |
| `continuation.prefix_chars` | 3000 | 单章前文注入上限（字） |
| `continuation.timeout_minutes` | 0（不限） | 可选推演超时；0=不限制，遵循项目"不写死超时"约定 |

### 5.8 边界与约束

- **失败容忍**：并行生成候选，单个候选失败不影响其他候选返回；全部失败给出明确错误与重试入口。
- **并发限制**：同一时间同一工作区仅允许一个推演任务（复用会话/任务注册模式）；中止复用 chat abort 链路。
- **写入安全**：提交复用 workspacechange 原子写入，不覆盖用户未保存的编辑器内容（revision 校验）。
- **范围**：本轮仅覆盖写作模式章节续写；游戏模式（interactive story）不涉及，交互保持独立。
- **与现有 `/continue` 的关系**：`/continue`（agent 对话续写）保留不动；推演是独立的显式交互入口，两者并存、互不影响。
- **双语**：所有弹窗、按钮、空状态、错误提示中英双语。
- **主题**：候选卡片、配置表单遵循 light/dark 双主题与既有组件库（shadcn/ui）。

## 6. 全局约束（所有需求共同遵守）

- 前后端字段命名一致；API 结构稳定；涉及 workspace 内用户内容写入一律先备份或走可撤销链路。
- 注入模型的所有片段有明确来源与大小上限（见 5.5）；不把无限历史塞进提示词。
- 新增交互均中英双语；布局自适应（窄屏/宽屏/长文本/空数据）；light/dark 双主题。
- 一级菜单行为不变：不新增/修改共享菜单切换逻辑；所有操作由用户显式触发。
- 版本发布时同步 CHANGELOG / README / 版本号（发布流程沿用）。

## 7. 验收标准（概要）

1. 作品目录视图可见导出/导入入口；导出范围与格式可选，下载正常，空状态提示双语。
2. 格式导入完整复用现有流程；材料导入识别正确、写入前备份、可回滚。
3. 大纲/规则/粗细纲三项均可独立导出下载与导入覆盖（含备份）。
4. Skills AI 对话页可完成"对话 → 草稿 → 预览编辑 → 导入生效"全流程；导入后 Skill 立即可用。
5. 续写推演按 短/中/长 三级与 方向/片段 粒度产出候选；选择/编辑/提交（新建章节或追加章末）落盘正确；失败容忍与中止可用；上下文全部有界。
6. 所有新功能在写作模式与既有页面集成下无回归；测试覆盖见《04-test-cases.md》。
