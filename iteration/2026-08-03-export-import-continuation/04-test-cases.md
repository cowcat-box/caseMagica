# 测试用例

> 迭代：2026-08 · 状态：随实现执行 · 关联：《02-prd.md》
> 类型约定：U=单元测试（纯函数/解析器/边界，单测 ≤1s）、I=集成测试（API/服务链路/workspace 状态）、M=手动验证（浏览器页面）。

---

## 1. 需求一：作品目录导出

| ID | 类型 | 场景 | 步骤 | 预期 |
|---|---|---|---|---|
| EXP-001 | U | zip 打包器 | 给定"章节+设定+分卷"虚拟文件清单 | 生成 zip 保持原相对目录结构（`chapters/v00001-卷名/ch00001-第1章-标题.md`、`setting/outline.md`、根级 `CREATOR.md`） |
| EXP-002 | U | 章节正文 md 导出 | 多分卷书籍 | 每个非空章节生成独立 md，正文与标题一致，空章节跳过 |
| EXP-003 | U | txt 导出复用 | 现有 ExportText 行为 | 与现有 `/api/books/export?format=txt` 输出一致（不回归） |
| EXP-004 | U | 勾选内容映射 | 勾选组合 → 请求参数 | 参数编码正确：章节/细纲(最新|全部)/大纲/规则/进度/角色状态/灵感/元数据 |
| EXP-005 | U | 空书籍导出 | 无任何非空章节且无设定文件 | 明确错误"没有可导出的内容"，非部分成功 |
| EXP-006 | I | 导出 API | 组合勾选 → GET 导出 | 200 + Content-Disposition 文件名正确 + zip 内容校验通过 |
| EXP-007 | M | 导出弹窗 | 浏览器操作 | 勾选/全选/格式联动正确；下载文件打开内容与勾选一致；无内容时提示双语空状态；light/dark 正常 |
| EXP-008 | M | 单文件导出 | 仅勾选"大纲" | 直接下载 `outline.md`（非 zip） |

## 2. 需求二：作品目录导入

| ID | 类型 | 场景 | 步骤 | 预期 |
|---|---|---|---|---|
| IMP-001 | U | 材料识别（标准名） | 文件名 `outline.md`/`CREATOR.md`/`progress.md`/`character-states.md`/`ideas.md` | 各自映射到正确目标路径 |
| IMP-002 | U | 材料识别（非标准名） | `大纲2.md`、`细纲v3.md` | 识别失败 → 返回候选类型列表，由调用方选择 |
| IMP-003 | U | 细纲自动编号 | 已存在 `group1.md`..`group3.md` | 新细纲落位 `group4.md`，不覆盖 |
| IMP-004 | U | 备份逻辑 | 目标文件已存在 | 写入前备份到 `.casemagica/backups/settings-import/<timestamp>/`，备份文件与原文件一致 |
| IMP-005 | I | 材料导入 API | 非标准名+手动类型 → 导入 → 读取 | 落位正确；原文件已备份；响应含备份路径 |
| IMP-006 | I | 格式导入复用 | 走现有 import-novel 链路 | 行为与 HomeView 入口完全一致（复用同一实现，不重复逻辑） |
| IMP-007 | M | 导入弹窗 | 选择 md 文件 | 识别摘要展示（类型→目标路径→备份位置）；确认后写入；侧边栏文件树刷新 |
| IMP-008 | M | 双入口一致性 | HomeView 与作品目录的格式导入 | 两入口表现一致 |

## 3. 需求三：书籍设定单文件导入导出

| ID | 类型 | 场景 | 步骤 | 预期 |
|---|---|---|---|---|

## 4. 需求四：Skills AI 对话页

| ID | 类型 | 场景 | 步骤 | 预期 |
|---|---|---|---|---|
| SKL-001 | U | 草稿区文件布局 | create_skill_draft 写入 | `.casemagica/skill-drafts/<name>/` 含 SKILL.md + 附加文件 + meta.json（时间/来源工作区） |
| SKL-002 | U | frontmatter 校验 | 非法 name/缺 description | 草稿创建拒绝，返回明确错误 |
| SKL-003 | U | 同名冲突 | 草稿名与已有 skill 同名 | 确认导入时提示"覆盖/改名"，不静默覆盖 |
| SKL-004 | I | 对话→草稿→导入全链路 | chat 工具 create_skill_draft → SSE 事件 → POST /api/skills → 删除草稿 | 导入后 `GET /api/skills` 可见新 skill，草稿区已清理 |
| SKL-005 | I | 草稿丢弃 | 用户丢弃草稿 | 草稿目录移动至备份区，可恢复 |
| SKL-006 | M | AI 对话页 | Skills → AI 对话 → 描述需求 | 对话正常流式；出现"Skill 草稿就绪"卡片；查看/编辑/导入/丢弃操作可用 |
| SKL-007 | M | 导入后立即可用 | 导入新 skill | Skills 列表出现；写作对话中 `/skill名` 可被加载（不回归） |

## 5. 需求五：续写推演（重点）

### 5.1 后端核心

| ID | 类型 | 场景 | 步骤 | 预期 |
|---|---|---|---|---|
| CON-001 | U | 深度/粒度/候选数映射 | 短→2~3 方向级；中→3 方向/片段；长→2~3 片段级 | 参数校验与默认值正确；非法组合（短+片段级）拒绝或自动降级（明确规则） |
| CON-002 | U | 上下文组装有界性 | 锚点章节+大纲+规则+细纲+风格 | 每片段有上限（5.5 表）；总量可预估；无无限增长源 |
| CON-003 | U | 候选 JSON 解析 | 合法/非法 LLM 输出 | 非法输出走 json_fallback 兼容；失败候选标记失败不影响其他 |
| CON-004 | U | 章节命名 | 提交新建章节 | 生成 `ch0000N-标题.md`，编号取最大 +1，标题清洗 |
| CON-005 | U | 追加章末 | 锚点章节存在 | 追加正文并保留原内容，不改变 confirmed 状态 |
| CON-006 | U | 落盘结构 | 推演任务 | `.casemagica/continuations/<task-id>/` 含 request.json + candidates/，可恢复 |
| CON-007 | U | 并发限制 | 同工作区第二个推演 | 拒绝并提示已有进行中推演 |
| CON-008 | U | 删除记录 | 删除推演任务 | 目录移动至 `.casemagica/backups/`，非物理删除 |
| CON-009 | I | 推演 API 全流程 | 发起 → 事件流 → 中止 | SSE 事件序列完整（candidate_start/delta/done/explore_done/error）；中止后任务标记 cancelled；失败候选不影响成功候选 |
| CON-010 | I | 提交 API（新建/追加） | 编辑后候选 → 提交 | 文件内容=编辑后内容；走 workspacechange 账本（变更审阅可见、可撤销）；revision 校验冲突时拒绝 |
| CON-011 | I | 重启恢复 | 任务进行中重启 → 列表 | 历史推演任务可见，已完成候选可读 |
