## 4. 风险与注意点（验证时重点关注）

1. **导出 zip 中文文件名**：zip 内文件名编码（GBK vs UTF-8 flag）在不同系统解压的兼容性；Windows 资源管理器中文名乱码风险 → 验证时确认 macOS 解压正常，并在 CHANGELOG 注明已知限制（如有）。
2. **SSE 断线重连**：推演中刷新/切网络，`tasks/:id/stream` 重连是否无重复候选（按 task_id + index 幂等渲染）。
3. **并发互斥**：同工作区第二个推演请求被拒提示；中止后任务状态正确（cancelled）。
4. **revision 冲突**：提交时编辑器有未保存修改 → 前端提示保存；服务端 revision 校验拒绝过期提交。
5. **跨工作区草稿**：Skill 草稿用户级共享，两个工作区同时看到同一草稿的并发编辑 → 草稿保存采用版本号或覆盖策略（本期以覆盖+时间戳为准，注明）。
